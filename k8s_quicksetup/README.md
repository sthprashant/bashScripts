# K8S QUICK SETUP

**Description**
This script automates the set up of K8S cluster (using `k3d`) and the [MongoDB k8s operator](https://www.mongodb.com/docs/kubernetes/current/tutorial/install-k8s-operator/).

Ideally this can be passed as **User Data** for ec2-instances (or equivalent)

Make sure you comply with [MongoDB’s licensing](https://www.mongodb.com/legal).
